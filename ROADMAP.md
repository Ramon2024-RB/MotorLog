# MotorLog Roadmap

MotorLog ist eine private Fahrzeug-, Tank- und Kostenverwaltung für iOS und Android.

## Aktueller Stand

- [x] Flutter-Projekt erstellt
- [x] iPhone-Simulator eingerichtet
- [x] Erste MotorLog-Oberfläche erstellt
- [x] Grundlegende Ordnerstruktur angelegt
- [x] Git eingerichtet
- [x] Riverpod, go_router, SQLite, path und UUID installiert
